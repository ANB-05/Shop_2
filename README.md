# 🛒 E-Commerce Store

A modern and responsive e-commerce website built with React, TypeScript, and Tailwind CSS.

## 🚀 Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Context API

## ✨ Features

- 🏠 Home page
- 🛍️ Store page
- 🛒 Shopping cart
- ➕ Increase and decrease product quantity
- 🗑️ Remove products from the cart
- 📱 Fully responsive design
- 📖 About Us page
- 📞 Contact Us page
- 🎨 Modern UI with Tailwind CSS
- 🧭 Client-side routing with React Router
- 🖼️ Interactive image effects

## 📦 Installation

Clone the repository:

```bash
git clone <repository-url>
````

Navigate to the project directory:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the URL shown in the terminal in your browser.

## 🏗️ Build

To create a production build:

```bash
npm run build
```
